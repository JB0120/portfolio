## ABOUT

아이디어를 실제 화면으로 구현하고,
작은 디테일까지 완성도를 높이는 것을 중요하게 생각합니다.

디자인의 의도를 이해하고 사용자 경험을 고려하며,
인터랙션과 유지보수성을 함께 고민하는
웹 퍼블리셔의 개인 포트폴리오입니다.

## KEY FEATURES

- **Landing Animation** — 인터랙티브한 인트로 화면
- **Infinite Slider** — 무한 반복 아이콘 슬라이드
- **Contact Modal** — 이메일 복사 및 외부 링크 연결
- **UI Interaction** — CSS 및 JavaScript 기반 인터랙션
